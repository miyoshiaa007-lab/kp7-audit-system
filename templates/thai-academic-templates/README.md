# เทมเพลตงานวิจัย 5 บท และผลงานทางวิชาการ (PA) ตามมาตรฐานวิชาการไทย

ชุดเทมเพลตนี้จัดทำจากการศึกษาโครงสร้างไฟล์ตัวอย่าง PA 4 ที่แนบมา 2 ไฟล์
(รายละเอียดผลการศึกษาอยู่ที่ [`analysis/STRUCTURE_ANALYSIS.md`](analysis/STRUCTURE_ANALYSIS.md))
แล้วนำมาสร้างเป็น **3 ส่วน**:

1. **สคริปต์ Python (python-docx)** สร้างไฟล์ Word เทมเพลต (`.docx`) — [`docx_generator/`](docx_generator/)
2. **ไฟล์ Word เทมเพลตที่สร้างไว้แล้ว** พร้อมใช้งานทันที — [`output/`](output/)
3. **เทมเพลต LaTeX** สำหรับ Overleaf / TeXstudio — [`latex/`](latex/)

ทั้งสองรูปแบบเอกสาร (Word และ LaTeX) ใช้สเปกเดียวกัน:

| รายการ | ค่าที่ใช้ |
|---|---|
| ฟอนต์ | TH Sarabun New ทุกระดับ (เนื้อหา 16pt, หัวข้อรอง 18pt ตัวหนา, หัวข้อบท/ตอน 20pt ตัวหนา) |
| ขอบกระดาษ | บน 3.00 ซม. / ล่าง 2.54 ซม. / ซ้าย 3.81 ซม. (เผื่อเข้าเล่ม) / ขวา 2.54 ซม. |
| การจัดย่อหน้า | Thai Distribute Justify ตามไฟล์ตัวอย่างที่แนบ |
| เลขหน้า | ส่วนหน้า (ปก/บทคัดย่อ/สารบัญ) = พยัญชนะไทย **ก ข ค ...**, ส่วนเนื้อหา = เลขอารบิก **1 2 3 ...** (นับใหม่ทั้งสองส่วน) |
| ตาราง | เส้นขอบเต็ม หัวตารางตัวหนาพื้นเทาอ่อน ตรงตามรูปแบบตารางในไฟล์ตัวอย่าง PA 4 ที่แนบ |

> **หมายเหตุสำคัญ**: เทมเพลตทั้งหมดเป็น "โครงร่างเปล่า" ที่มีข้อความในวงเล็บเหลี่ยม
> `[ ... ]` ให้ผู้ใช้แทนที่ด้วยข้อมูลจริงของตนเอง — ไม่ได้คัดลอกเนื้อหาส่วนบุคคล
> จากไฟล์ตัวอย่างที่แนบมา (เช่น ชื่อผู้จัดทำ/ตัวเลขผลงานจริง) เพราะเป็นข้อมูลเฉพาะบุคคล
> ของเจ้าของไฟล์ต้นฉบับ

## 1) เทมเพลต Word (python-docx)

### วิธีสร้างไฟล์ .docx จากสคริปต์

```bash
cd docx_generator
pip install python-docx pythainlp
python build_5chapter_template.py   # -> ../output/5-Chapter-Research-Template.docx
python build_pa_template.py         # -> ../output/PA-Academic-Report-Template.docx
```

### โครงสร้างสคริปต์

- `thai_text_utils.py` — แทรก Zero-Width Space ระหว่างคำไทย (กันข้อความล้นขอบกระดาษ)
- `docx_common.py` — โมดูลกลาง: สไตล์ฟอนต์/หัวข้อ, การตั้งค่าหน้ากระดาษ, ระบบเลขหน้า
  2 รูปแบบในเล่มเดียว (ใช้ OOXML `w:pgNumType` แบบเดียวกับที่ Word ใช้จริง ไม่ใช่การพิมพ์
  ตัวอักษรปลอม), ตัวช่วยสร้างตารางแบบเส้นเต็ม, กล่อง placeholder รูปภาพ, บล็อกลงนาม
- `build_5chapter_template.py` — ประกอบเทมเพลตงานวิจัย 5 บท (ปก → ส่วนหน้า ก ข ค →
  บทที่ 1-5 → บรรณานุกรม → ภาคผนวก → ประวัติผู้วิจัย)
- `build_pa_template.py` — ประกอบเทมเพลต PA (ปก → สารบัญ → ส่วนที่ 1 ข้อมูลทั่วไป →
  บล็อกตัวชี้วัดที่ทำซ้ำได้ `build_indicator_block()` → ภาคผนวก)

### ไฟล์ที่ได้ (`output/`)

- `5-Chapter-Research-Template.docx`
- `PA-Academic-Report-Template.docx`

เปิดด้วย Microsoft Word แล้วกด **Ctrl+A → F9** (หรือคลิกขวา > Update Field) เพื่ออัปเดต
สารบัญ/เลขหน้าให้ตรงกับเนื้อหาที่พิมพ์จริง

## 2) เทมเพลต LaTeX (Overleaf / TeXstudio)

โฟลเดอร์ `latex/5chapter/` (งานวิจัย 5 บท) และ `latex/pa/` (ผลงานทางวิชาการ/PA)
แยกไฟล์ตามส่วนของเอกสาร:

```
latex/5chapter/
├── main.tex            # ไฟล์หลัก รวมทุกไฟล์ย่อย
├── preamble.tex         # ฟอนต์/ระยะขอบ/สไตล์หัวข้อ/ระบบเลขหน้า ก ข ค + 1 2 3
├── cover.tex             # หน้าปก
├── approval.tex, abstract_th.tex, abstract_en.tex, acknowledgement.tex
├── chapters/chapter1.tex ... chapter5.tex
├── bibliography.tex, appendix.tex, cv.tex
├── references.bib
└── fonts/                # นำไฟล์ฟอนต์ TH Sarabun New มาวางที่นี่

latex/pa/
├── main.tex, preamble.tex, cover.tex
├── part1_general.tex     # ส่วนที่ 1 ข้อมูลทั่วไป
├── part2_domain1.tex     # ส่วนที่ 2 ด้านที่ 1 (ต้นแบบสำหรับทำซ้ำด้าน/ตัวชี้วัดอื่น)
├── part3_domain2.tex     # ส่วนที่ 3 ด้านที่ 2
├── appendix.tex
└── fonts/
```

### วิธีใช้บน Overleaf

1. สร้างโปรเจกต์ใหม่ > Upload Project แล้วอัปโหลดทั้งโฟลเดอร์ (`latex/5chapter/` หรือ `latex/pa/`)
2. เมนู **Menu > Compiler** เลือก **XeLaTeX** (จำเป็น เพราะใช้ `fontspec`/`polyglossia`)
3. นำไฟล์ฟอนต์ TH Sarabun New (`.ttf`) ไปวางในโฟลเดอร์ `fonts/` ของโปรเจกต์
   (ถ้าไม่มีไฟล์ฟอนต์ ให้แก้ `preamble.tex` เปลี่ยน `\setmainfont{TH Sarabun New}[...]`
   เป็น `\setmainfont{Sarabun}` ซึ่งเป็นฟอนต์ตระกูลใกล้เคียงที่มีอยู่แล้วบน Overleaf)
4. คอมไพล์ `main.tex`

### วิธีใช้บน TeXstudio (เครื่องตนเอง)

ต้องติดตั้ง TeX Live/MiKTeX ที่มี `xelatex` และ `biber` (สำหรับเทมเพลต 5 บทที่ใช้ biblatex)

```bash
xelatex main.tex
biber main        # เฉพาะเทมเพลต 5chapter ที่มีบรรณานุกรม
xelatex main.tex
xelatex main.tex  # รันซ้ำให้สารบัญ/การอ้างอิงครบ
```

ตั้งค่าใน TeXstudio: Options > Configure TeXstudio > Build > Default Compiler = **XeLaTeX**

### ระบบเลขหน้า ก ข ค / 1 2 3 (ผ่านการทดสอบคอมไพล์จริงแล้ว)

`preamble.tex` ทั้งสองชุดกำหนดคำสั่ง:

- `\thaifrontmatter` — เริ่มเลขหน้าเป็นพยัญชนะไทย ก ข ค ... (เรียกหลังหน้าปก)
- `\mainbodymatter` — เปลี่ยนเป็นเลขอารบิก 1 2 3 ... นับใหม่จาก 1 (เรียกก่อนบทที่ 1 /
  ก่อนเนื้อหาส่วนที่ 2 เป็นต้นไป)

ทดสอบคอมไพล์แล้วได้ผลลัพธ์ถูกต้อง: หน้าปกไม่มีเลขหน้า → หน้าถัดไปแสดง ก, ข, ค, ...
ตามลำดับ → เมื่อเข้าสู่เนื้อหาแสดง 1, 2, 3, ... ต่อเนื่องจนจบเล่ม

## 3) เกณฑ์ ก.ค.ศ. / สพฐ.

โครงสร้างตารางเกณฑ์การให้คะแนน (Scoring Rubric), ตารางวิเคราะห์ความสอดคล้อง,
และขั้นตอน PDCA ในเทมเพลต PA อ้างอิงรูปแบบจากไฟล์ตัวอย่าง PA 4 ที่แนบมาโดยตรง
(ซึ่งจัดทำตามหนังสือ ว9/2564 ของสำนักงาน ก.ค.ศ. และแบบประเมินของ สพฐ.) ผู้ใช้ยังคง
ต้องนำ **ข้อความเกณฑ์การประเมินจริง** ตามตำแหน่ง/วิทยฐานะ/สังกัดของตนเองจากประกาศ
ก.ค.ศ. ฉบับล่าสุดมาใส่แทนข้อความในวงเล็บเหลี่ยม เนื่องจากเกณฑ์อาจแตกต่างกันตาม
