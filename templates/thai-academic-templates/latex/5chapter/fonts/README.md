# โฟลเดอร์ฟอนต์

วางไฟล์ฟอนต์ TH Sarabun New ที่นี่ (เช่น `THSarabunNew.ttf`, `THSarabunNew Bold.ttf`,
`THSarabunNew Italic.ttf`, `THSarabunNew BoldItalic.ttf`) แล้ว preamble.tex
จะเรียกใช้งานให้อัตโนมัติผ่าน fontspec

หากไม่มีไฟล์ฟอนต์ ให้แก้ preamble.tex ตรงคำสั่ง `\setmainfont{TH Sarabun New}[...]`
เป็น `\setmainfont{Sarabun}` (ฟอนต์ตระกูลใกล้เคียงที่มีอยู่แล้วบน Overleaf/Google Fonts)
